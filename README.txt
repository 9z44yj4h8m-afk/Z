ALMOGHANI LIVE — Arabic First IPTV Catalog
==========================================

الملف الرئيسي:
ALMOGHANI_LIVE_sorted.html

الوظائف:
1. تنزيل القائمة العامة مباشرة من:
   https://cdn.jsdelivr.net/gh/streamline-iptv/iptv-playlists@dist/index.m3u
2. تصنيف القنوات حسب group-title (مع دعم عدة أقسام للقناة الواحدة).
3. ترتيب القنوات داخل كل قسم: السعودية، الخليج، بقية العرب، الأجنبية.
4. التجميع حسب tvg-id والدولة مع إبقاء روابط البث البديلة.
5. عرض شعارات القنوات والمحطات المفضلة والبحث ومشغل HLS.
6. زر «تصدير M3U مرتب» ينزّل ملف M3U مصنفًا حسب نوع القناة، وبداخله القنوات العربية أولًا.
7. تحديث يدوي لجلب أحدث نسخة من المصدر.

طريقة الاستخدام:
- ارفع ملف HTML إلى استضافة HTTPS مثل GitHub Pages، ثم افتحه من المتصفح.
- انتظر تحميل القنوات؛ ثم جرّب الأقسام.
- اضغط «تصدير M3U مرتب» لتحميل ملف القنوات المنظم، قابل للاستيراد في أغلب تطبيقات IPTV.
- يمكن تسمية الملف index.html عند رفعه إلى جذر موقع جديد.
- لا ترفع هذا الملف بدل index.html الأصلي لموقعك دون الاحتفاظ بنسخة احتياطية.

ملاحظات مهمة:
- التشغيل غير مضمون لكل القنوات: قد تفرض المصادر قيود CORS أو حظرًا جغرافيًا.
- لا يُخزن ملف M3U كامل مسبقًا ضمن هذه الحزمة؛ يتم جلبه عند فتح صفحة HTML.
- الحزمة واجهة مستقلة وليست تعديلًا مباشرًا لمستودع GitHub الخاص بك.
- المصدر: Doubo Public Channel Directory / streamline-iptv (CC BY 4.0 للفهرسة).
- جميع حقوق البث لأصحابها.
